## 3. Текущая архитектура — проверено по main

На момент последней проверки сайт реализован как статическая страница GitHub Pages.

### HTML

- Главная разметка находится в `index.html`.
- Встроенных блоков JavaScript в HTML нет: все скрипты подключаются из отдельных файлов.
- В `index.html` подключён 31 внешний JavaScript-файл.

### Корректировка устойчивости раскрытого меню (2026-11-08)

- Причина нестабильности: у раскрытого меню одновременно задавались фиксированная высота в `dvh` и отдельное ограничение максимальной высоты всей шапки. При изменении масштаба/видимой области Safari эти размеры могли конфликтовать и обрезать содержимое.
- В `styles-14.css` добавлена локальная мобильная схема: раскрытая оболочка получает предсказуемую высоту до 88dvh; меню занимает оставшееся пространство через flex вместо собственной фиксированной высоты.
- Внутри меню включена самостоятельная вертикальная прокрутка с поддержкой iOS momentum scrolling. Верхняя панель шапки остаётся неподвижной.
- Инь-янь закреплён в верхней части внутренней области меню; список разделов, кнопка связи и социальные иконки остаются обычными элементами потока и не выталкиваются за пределы окна.
- Убран прежний большой верхний отступ списка только в состоянии открытого мобильного меню. Верхняя зона меню оставлена под переключатель темы.
- HTML, JavaScript, ссылки, тексты, анимация открытия/закрытия, положение закрытой шапки и остальные секции не менялись.
- Требуется пользовательская проверка на iPhone Safari: открыть меню после прокрутки страницы; проверить масштабирование pinch и системный zoom; убедиться, что инь-янь виден, а при нехватке места прокручивается внутреннее содержимое. Публикация GitHub Pages отдельно не подтверждена.


### Завершение интерактивности и анимации меню (2026-11-08)

- В styles-05.css обнаружено исходное правило pointer-events:none на общей нижней шапке. Внутренняя панель шапки отдельно получала pointer-events:auto, но само меню является её соседним элементом. Поэтому видимые элементы раскрытого меню могли не получать нажатия.
- В конце styles-14.css добавлено локальное восстановление pointer-events:auto для раскрытого меню и его дочерних элементов.
- В js/hero-menu-trigger.js исправлена обработка ссылок: раньше обработчик сразу делал меню inert во время клика, что могло отменять стандартную активацию ссылки. Для внутренних ссылок теперь предотвращается прежний переход, меню закрывается, затем целевой раздел плавно прокручивается в область просмотра и обновляется hash URL. Для внешних ссылок закрытие меню откладывается до следующего task, чтобы браузер успел открыть адрес.
- Проверены все шесть внутренних пунктов: #program-all, #about, #learning-format, #reviews, #pricing, #faq; все соответствующие ID существуют в index.html.

- Jelly-эффект был заблокирован: базовое правило шапки задавало animation:none!important, а правило открытого состояния назначало анимацию без !important. - В HTML остаются декоративные span для Instagram и YouTube без адресов. Не превращать их в ссылки на случайные страницы платформ; для полной кликабельности этих двух иконок нужны официальные URL аккаунтов проекта.

## 3. Что изменено

### 3.1 Футер сайта

Файл: `index.html`.

Было:

```html
<a href="#privacy-policy" ...>Политика данных</a> · <a href="https://t.me/START_XXX_STOP" target="_blank" rel="noopener noreferrer">Telegram</a>
```

Стало:

```html
<a href="#privacy-policy" ...>Политика данных</a> · <a href="https://t.me/start_xxx_stop" target="_blank" rel="noopener noreferrer">Разработка сайта</a>
```

Поведение:

- надпись «Разработка сайта» расположена рядом с пунктом «Политика данных»;
- при нажатии открывается `https://t.me/start_xxx_stop` в новой вкладке;
- отдельная видимая ссылка «Telegram» удалена из футера;
- адрес Telegram больше не отображается в футере отдельным пунктом;
- `rel="noopener noreferrer"` сохранён, чтобы новая вкладка не получала доступ к `window.opener`;
- оформление не менялось: используются существующие стили футера, разделитель `·`, шрифт, цвет, подчёркивание и hover-эффект ссылок;
- адаптивность не менялась: структура `footer__in` и правило `flex-wrap` остались прежними, поэтому перенос строк на узких экранах работает как раньше.

1. **Автоматическая проверка футера в `scripts/check-site.mjs`.** Полезно добавить тест на точный адрес и отсутствие отдельной ссылки «Telegram», но это изменение за пределами футера и прямо запрещено условием задачи. Точный следующий шаг: отдельным PR добавить в `check-site.mjs` проверки:
   - футер содержит `href="https://t.me/start_xxx_stop"`;
   - у ссылки есть `target="_blank"` и `rel="noopener noreferrer"`;
   - в футере нет отдельного текста `Telegram`.
2. **Supabase schema, RLS, Edge Functions, логи и advisors.** Нет доступа к Supabase MCP в этом запуске. Нужен отдельный запуск с доступом; production-данные не затрагивались.
3. **Сетевая доступность Telegram-ссылки.** Проверен только точный `href` в HTML. Если владельцу нужна проверка доступности, следует открыть ссылку вручную или добавить безопасный HTTP smoke-check без передачи каких-либо данных проекта.
4. **Визуальная проверка на мобильных.** Структура и CSS футера не менялись, поэтому риск низкий. Для полного подтверждения нужно открыть страницу на ширине 320–390 px и убедиться, что надпись переносится без горизонтального скролла.
